# Книжная полка (Book Shelf)

Веб-приложение для учёта прочитанных книг с разделением на клиентскую часть и серверную часть (REST API на чистом Node.js).

---

##  Инструкция по запуску

Для работы приложения необходим установленный **Node.js** (версии 18+).

### 1. Запуск бэкенд-сервера
В корне проекта выполните команду:
```
node server.js
```
Сервер запустится по адресу: `http://127.0.0.1:3000/`.

### 2. Запуск фронтенда
Откройте файл `index.html` в браузере.

---

##  REST API

Базовый URL: `http://127.0.0.1:3000`

### Модель данных книги (Book)
```json
{
  "id": 1730550000000,
  "title": "1984",
  "author": "George Orwell",
  "status": "read",
  "rating": 5
}
```
* `id` (`Number`): Уникальный числовой идентификатор, генерируется сервером (`Date.now()`).
* `title` (`String`): Название книги (обязательное, непустая строка).
* `author` (`String`): Автор книги (по умолчанию `"Неизвестный автор"`).
* `status` (`String`): Статус прочтения (`"want"` — хочу прочитать, `"reading"` — читаю, `"read"` — прочитано).
* `rating` (`Number | null`): Оценка от 1 до 5 (доступна только при статусе `"read"`, для остальных статусов всегда `null`).

---

### Эндпоинты

#### 1. Получение списка книг
* **Метод:** `GET`
* **URL:** `/books`
* **Query-параметры (фильтрация):**
  * `id` — поиск по точному числовому идентификатору (`/books?id=1`)
  * `title` — поиск по подстроке в названии без учёта регистра (`/books?title=gatsby`)
  * `author` — поиск по подстроке в имени автора без учёта регистра (`/books?author=lee`)
  * `status` — фильтрация по статусу, поддерживает множественный выбор (`/books?status=want&status=reading`)
* **Ответ сервера:** `200 OK`, массив объектов книг в формате JSON (при отсутствии совпадений возвращается пустой массив `[]`).

---

#### 2. Добавление новой книги
* **Метод:** `POST`
* **URL:** `/books`
* **Заголовки:** `Content-Type: application/json`
* **Тело запроса (Request Body):**
```json
{
  "title": "Мастер и Маргарита",
  "author": "Михаил Булгаков",
  "status": "want"
}
```
* **Валидация:**
  * Название обязательно и не должно состоять из одних пробелов (код `400`).
  * Статус должен быть одним из: `"want"`, `"reading"`, `"read"` (код `400`).
  * Оценка, если передана, должна быть целым числом от 1 до 5 (код `400`).
* **Ответ сервера при успехе:** `201 Created` с телом созданной книги (включая `id`).

---

#### 3. Частичное обновление книги
* **Метод:** `PATCH`
* **URL:** `/books/:id`
* **Заголовки:** `Content-Type: application/json`
* **Тело запроса:** передаются только изменяемые поля:
```json
{
  "status": "read",
  "rating": 5
}
```
* **Особенности:**
  * Идентификатор книги защищён от перезаписи (`id` не меняется).
  * При переводе статуса в `"want"` или `"reading"` оценка автоматически сбрасывается в `null`.
* **Коды ответов:**
  * `200 OK` — книга успешно обновлена.
  * `400 Bad Request` — некорректный ID или невалидные данные.
  * `404 Not Found` — книга с указанным ID не найдена.

---

#### 4. Удаление книги
* **Метод:** `DELETE`
* **URL:** `/books/:id`
* **Коды ответов:**
  * `200 OK` — книга удалена (`{ "message": "Книга успешно удалена" }`).
  * `400 Bad Request` — некорректный ID (`NaN`).
  * `404 Not Found` — книга с указанным ID не найдена.

---

#### 5. Междоменные запросы (CORS) и Preflight
* Сервер обрабатывает предварительные запросы браузера `OPTIONS` и возвращает статус `204 No Content` со следующими заголовками:
  * `Access-Control-Allow-Origin: *`
  * `Access-Control-Allow-Methods: GET, POST, PATCH, DELETE, OPTIONS`
  * `Access-Control-Allow-Headers: Content-Type`
