# Книжная полка (Book Shelf)

Веб-приложение для учёта прочитанных книг с разделением на клиентскую часть (Vanilla JS) и серверную часть (REST API на чистом Node.js).

---

## Пошаговое руководство по запуску с нуля

### Шаг 1. Проверка и установка Node.js
Для работы сервера необходима среда выполнения **Node.js** (версии 18 или новее).

1. Проверьте, установлен ли Node.js на компьютере. Откройте терминал (PowerShell / Командная строка в Windows, либо Terminal в macOS/Linux) и выполните команду:
   ```bash
   node -v
   ```
   * Если отобразилась версия (например, `v18.x.x`, `v20.x.x` или выше) — Node.js уже готов, переходите к Шагу 2.
2. Если команда не найдена или версия ниже 18:
   * Перейдите на официальный сайт: [nodejs.org](https://nodejs.org/).
   * Скачайте последнюю версию для вашей операционной системы.
   * Запустите скачанный файл установщика и завершите установку, следуя стандартным подсказкам мастера («Next»).
   * После установки перезапустите терминал и повторите команду `node -v` для подтверждения.

---

### Шаг 2. Получение файлов проекта
1. **Через Git (рекомендуется):**
   Склонируйте репозиторий на свой компьютер и перейдите в созданную папку:
   ```bash
   git clone https://github.com/d0kus/book-shelf.git
   cd book-shelf
   ```
   При необходимости переключитесь на ветку с серверной частью:
   ```bash
   git checkout iteration-1
   ```
2. **Или скачиванием ZIP-архива:**
   На странице репозитория на GitHub нажмите зелёную кнопку **Code** → **Download ZIP**, распакуйте скачанный архив в удобное место и откройте эту папку в терминале или редакторе кода (например, VS Code).

>  **Обратите внимание:** проект реализован исключительно на встроенных возможностях Node.js (`node:http`, `node:url`) и нативном JavaScript. **Сторонних библиотек и зависимостей нет, выполнять команду `npm install` не требуется**

---

### Шаг 3. Запуск бэкенд-сервера
1. Откройте терминал и убедитесь, что вы находитесь в корневой папке проекта (где лежат файлы `server.js` и `index.html`).
2. Запустите сервер командой:
   ```bash
   node server.js
   ```
3. В терминале отобразится подтверждение:
   ```text
   Server running at http://localhost:3000/
   ```
   Сервер запущен и готов к обработке HTTP-запросов.
   *(Оставьте это окно терминала открытым во время работы с приложением. Чтобы остановить сервер, нажмите в терминале `Ctrl + C`).*

---

### Шаг 4. Запуск интерфейса (UI)

Для корректной работы веб-приложения по протоколу HTTP (а не через протокол `file://`), фронтенд необходимо запускать через локальный веб-сервер:

* **Вариант 1 (Рекомендуемый — через расширение Live Server в VS Code):**
  1. Откройте папку проекта в редакторе **VS Code**.
  2. Установите расширение **Live Server**, если оно ещё не установлено.
  3. Нажмите правой кнопкой мыши по файлу `index.html` и выберите **«Open with Live Server»**.
  4. Страница откроется в браузере по адресу `http://127.0.0.1:5500/` и автоматически подключится к запущенному серверу на порту 3000.

* **Вариант 2 (Через консольный HTTP-сервер npx serve):**
  Утилита `npx` уже встроена в Node.js, поэтому отдельная предварительная установка не требуется — утилита скачается и запустится автоматически:
  1. В отдельном окне терминала в папке проекта выполните команду:
     ```bash
     npx serve .
     ```
     *(при первом запуске утилита может запросить подтверждение установки — нажмите `y` и `Enter`).*

  2. Перейдите по адресу, который отобразится в терминале.

При загрузке страницы интерфейс выполнит запрос к бэкенду (`http://localhost:3000/books`), получит список книг и отобразит их на полке.

##  REST API

Базовый URL: `http://localhost:3000`

### Модель данных книги (Book)
```json
{
  "id": 1730550000000,
  "title": "1984",
  "author": "George Orwell",
  "status": "read",
  "rating": 5
}
```
* `id` (`Number`): Уникальный числовой идентификатор, генерируется сервером (`Date.now()`).
* `title` (`String`): Название книги (обязательное, непустая строка).
* `author` (`String`): Автор книги (по умолчанию `"Неизвестный автор"`).
* `status` (`String`): Статус прочтения (`"want"` — хочу прочитать, `"reading"` — читаю, `"read"` — прочитано).
* `rating` (`Number | null`): Оценка от 1 до 5 (доступна только при статусе `"read"`, для остальных статусов всегда `null`).

---

### Эндпоинты

#### 1. Получение списка книг
* **Метод:** `GET`
* **URL:** `/books`
* **Query-параметры (фильтрация):**
  * `id` — поиск по точному числовому идентификатору (`/books?id=1`)
  * `title` — поиск по подстроке в названии без учёта регистра (`/books?title=gatsby`)
  * `author` — поиск по подстроке в имени автора без учёта регистра (`/books?author=lee`)
  * `status` — фильтрация по статусу, поддерживает множественный выбор (`/books?status=want&status=reading`)
* **Ответ сервера:** `200 OK`, массив объектов книг в формате JSON (при отсутствии совпадений возвращается пустой массив `[]`).

---

#### 2. Добавление новой книги
* **Метод:** `POST`
* **URL:** `/books`
* **Заголовки:** `Content-Type: application/json`
* **Тело запроса (Request Body):**
```json
{
  "title": "Мастер и Маргарита",
  "author": "Михаил Булгаков",
  "status": "want"
}
```
* **Валидация:**
  * Название обязательно и не должно состоять из одних пробелов (код `400`).
  * Статус должен быть одним из: `"want"`, `"reading"`, `"read"` (код `400`).
  * Оценка, если передана, должна быть целым числом от 1 до 5 (код `400`).
* **Ответ сервера при успехе:** `201 Created` с телом созданной книги (включая `id`).

---

#### 3. Частичное обновление книги
* **Метод:** `PATCH`
* **URL:** `/books/:id`
* **Заголовки:** `Content-Type: application/json`
* **Тело запроса:** передаются только изменяемые поля:
```json
{
  "status": "read",
  "rating": 5
}
```
* **Особенности:**
  * Идентификатор книги защищён от перезаписи (`id` не меняется).
  * При переводе статуса в `"want"` или `"reading"` оценка автоматически сбрасывается в `null`.
* **Коды ответов:**
  * `200 OK` — книга успешно обновлена.
  * `400 Bad Request` — некорректный ID или невалидные данные.
  * `404 Not Found` — книга с указанным ID не найдена.

---

#### 4. Удаление книги
* **Метод:** `DELETE`
* **URL:** `/books/:id`
* **Коды ответов:**
  * `200 OK` — книга удалена (`{ "message": "Книга успешно удалена" }`).
  * `400 Bad Request` — некорректный ID (`NaN`).
  * `404 Not Found` — книга с указанным ID не найдена.

---

#### 5. Междоменные запросы (CORS) и Preflight
* Сервер обрабатывает предварительные запросы браузера `OPTIONS` и возвращает статус `204 No Content` со следующими заголовками:
  * `Access-Control-Allow-Origin: *`
  * `Access-Control-Allow-Methods: GET, POST, PATCH, DELETE, OPTIONS`
  * `Access-Control-Allow-Headers: Content-Type`

| 1 | Первичная загрузка | Открытие страницы через Live Server при запущенном сервере | Запрос `GET /books`, отрисовка захардкоженных книг | Книги успешно загружены и отображены в списке |
| 2 | Добавление валидной книги | Заполнение формы корректными данными и submit | Запрос `POST /books`, статус `201`, карточка добавлена на полку, форма очищена | Книга добавлена с присвоением ID от сервера |

| 4 | Серверная валидация статуса | Отправка `POST /books` со статусом `"unknown"` через POSTMAN | Сервер возвращает `400 Bad Request`, книга не добавляется | Статус 400, сообщение `{"error": "Некорректный статус книги"}` |
| 5 | Серверная валидация рейтинга | Отправка `POST /books` с рейтингом `10` или `3.5` | Сервер отклоняет запрос с кодом `400 Bad Request` | Статус 400, сообщение `{"error": "Оценка должна быть числом от 1 до 5"}` |

| 7 | Смена статуса и сброс оценки | Перевод книги из «Прочитано» в «Читаю» | `PATCH /books/:id`, статус `reading`, рейтинг автоматически сброшен в `null` | Звёзды стали неактивными, оценка стёрта, счётчики пересчитаны |
| 8 | Удаление книги | Клик по кнопке «Удалить» и подтверждение в диалоге `confirm` | Запрос `DELETE /books/:id`, статус `200`, удаление карточки | Книга удалена из DOM и из массива на сервере |
| 9 | Удаление несуществующей книги | Запрос `DELETE /books/999999` через POSTMAN | Сервер возвращает `404 Not Found` | Статус 404, `{"error": "Книга не найдена"}` |
| 10 | Падение/отключение сервера | Остановка сервера и попытка добавить/удалить книгу | Ошибка сети перехватывается, всплывает уведомление об ошибке | Всплывает плашка «Ошибка соединения», интерфейс остаётся неизменным (Pessimistic UI) |
| 11 | Фильтрация по нескольким статусам | Выбор чекбоксов «Прочитано» и «Читаю» | Фильтрация отображает только подходящие книги | Отображаются книги с выбранными статусами, счётчики актуальны |
