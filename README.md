# Книжная полка (Book Shelf)

Веб-приложение для учёта прочитанных книг с разделением на клиентскую часть (Vanilla JS), серверную часть (REST API на чистом Node.js) и надёжное реляционное хранилище данных (**PostgreSQL**).

---

##  Пошаговое руководство по запуску с нуля

### Шаг 1. Проверка и установка Node.js
Для работы сервера необходима среда выполнения **Node.js** (версии 18 или новее).

1. Проверьте, установлен ли Node.js на компьютере. В терминале выполните:
   ```bash
   node -v
   ```
   * Если отобразилась версия (`v18.x.x`, `v20.x.x` или выше) — всё готово.
   * Если команда не найдена — скачайте и установите Node.js с официального сайта: [nodejs.org](https://nodejs.org/).

---

### Шаг 2. Проверка и установка PostgreSQL
Для хранения данных используется реляционная СУБД **PostgreSQL**.

1. Убедитесь, что сервер PostgreSQL установлен и служба запущена на стандартном порту `5432`.
2. Если PostgreSQL ещё не установлен:
   * Скачайте установщик для вашей ОС с официального сайта: [postgresql.org/download](https://www.postgresql.org/download/).
   * При установке задайте пароль для суперпользователя `postgres` (запомните его).

---

### Шаг 3. Получение файлов проекта и установка зависимостей
1. Склонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone https://github.com/d0kus/book-shelf.git
   cd book-shelf
   ```
2. Установите необходимые зависимости (драйвер `pg` для работы с базой данных):
   ```bash
   npm install
   ```

---

### Шаг 4. Настройка переменных окружения (.env)
В корне проекта находится шаблон конфигурации `.env.example`. 

1. Создайте в корне проекта файл `.env` (скопировав `.env.example`):
   ```bash
   cp .env.example .env
   ```
2. Откройте файл `.env` и укажите свои параметры подключения к PostgreSQL (особенно ваш пароль):
   ```env
   DB_HOST=localhost
   DB_PORT=5432
   DB_USER=postgres
   DB_PASSWORD=your_password_here
   DB_NAME=book_shelf
   ```

---

### Шаг 5. Автоматическая инициализация базы данных и сидов
Для автоматического создания базы данных, таблиц и заполнения их тестовыми данными выполните команду:

```bash
npm run db:init
```

> **Что делает эта команда:**
> 1. Подключается к служебной базе `postgres`.
> 2. Проверяет наличие базы данных `book_shelf` и при необходимости создаёт её.
> 3. Переподключается к `book_shelf` и добавляет схему таблиц `books` и `notes` со связью `ON DELETE CASCADE`.
> 4. Наполняет таблицы начальными книгами и заметками к ним (Seed data).

---

### Шаг 6. Запуск бэкенд-сервера
Запустите сервер командой:

```bash
npm start
```
В терминале отобразится:
```text
Server running at http://127.0.0.1:3000/
```
*(Оставьте терминал открытым. Для остановки нажмите `Ctrl + C`).*

---

### Шаг 7. Запуск интерфейса (UI)

Фронтенд необходимо запускать через локальный веб-сервер:

* **Вариант 1 (VS Code Live Server — рекомендуется):**  
  Кликните правой кнопкой мыши по `index.html` → **«Open with Live Server»** (откроется по адресу `http://127.0.0.1:5500/`).
* **Вариант 2 (Через npx serve):**  
  В отдельном окне терминала выполните команду:
  ```bash
  npx serve .
  ```
  и откройте появившийся в консоли адрес в браузере.

##  REST API

Базовый URL: `http://localhost:3000`

### Модели данных

#### Книга (Book) с вложенными заметками
```json
{
  "id": 1,
  "title": "1984",
  "author": "George Orwell",
  "status": "read",
  "rating": 5,
  "created_at": "2026-11-20T10:00:00.000Z",
  "notes": [
    {
      "id": 1,
      "text": "Сильное произведение о тоталитаризме.",
      "created_at": "2026-11-20T10:05:00.000Z"
    }
  ]
}
```

#### Заметка (Note)
```json
{
  "id": 1,
  "book_id": 1,
  "text": "Перечитать главу 3",
  "created_at": "2026-11-20T10:05:00.000Z"
}
```

---

### Эндпоинты: Книги (/books)

| Метод | URL | Описание | Тело запроса | Ответ |
|---|---|---|---|---|
| `GET` | `/books` | Получение списка книг с агрегированными заметками. Поддерживает query-фильтры: `id`, `title`, `author`, `status`. | — | `200 OK`, массив объектов книг |
| `POST` | `/books` | Создание новой книги. | `{"title": "...", "author": "...", "status": "want"}` | `201 Created`, объект созданной книги |
| `PATCH` | `/books/:id` | Частичное обновление книги (статус, рейтинг, автор, название). | `{"status": "read", "rating": 5}` | `200 OK`, обновлённая книга |
| `DELETE` | `/books/:id` | Удаление книги. **Каскадно удаляет все связанные с ней заметки**. | — | `200 OK`, сообщение об успехе |

---

### Эндпоинты: Заметки (/notes)

| Метод | URL | Описание | Тело запроса | Ответ |
|---|---|---|---|---|
| `POST` | `/books/:id/notes` | Добавление новой заметки к книге с указанным `id`. | `{"text": "Текст заметки"}` | `201 Created`, созданная заметка |
| `PATCH` | `/notes/:id` | Редактирование текста существующей заметки по её `id`. | `{"text": "Обновлённый текст"}` | `200 OK`, обновлённая заметка |
| `DELETE` | `/notes/:id` | Удаление заметки по её `id`. | — | `200 OK`, удалённая заметка |

---

### CORS и Preflight
Сервер поддерживает CORS для всех доменов (`*`), обрабатывает Preflight-запросы `OPTIONS` и возвращает статус `204 No Content` со списком разрешённых методов: `GET, POST, PATCH, DELETE, OPTIONS`.

## Протестированные ручные сценарии (Test Cases)

| № | Сценарий | Действие | Ожидаемый результат | Фактический результат |
|---|---|---|---|---|
| 1 | Первичная загрузка и агрегация | Открытие страницы через Live Server при запущенном сервере и БД | Запрос `GET /books`, отдача книг вместе со вложенными массивами `notes` | Книги и все их заметки корректно отрисованы на странице |
| 2 | Добавление валидной книги | Заполнение формы книги и клик «Добавить» | Запрос `POST /books`, статус `201`, карточка отображается на полке с пустой секцией заметок | Книга добавлена в БД и в DOM, `notes: []` |
| 3 | Валидация пустого названия | Попытка добавить книгу без названия | Клиентская валидация останавливает отправку, поле подсвечивается | Запрос на сервер не уходит |
| 4 | Серверная валидация статуса/рейтинга | Отправка `POST /books` с некорректным статусом или оценкой вне диапазона 1–5 | Сервер возвращает `400 Bad Request` с описанием ошибки | Статус 400, запись в БД не создаётся |
| 5 | Смена статуса и сброс оценки | Перевод книги из «Прочитано» в «Читаю» | `PATCH /books/:id`, статус `reading`, рейтинг в БД сбрасывается в `null` | Звёзды деактивированы, рейтинг сброшен |
| 6 | Добавление заметки к книге | Ввод текста в поле заметки карточки и клик «Добавить» | Запрос `POST /books/:id/notes`, статус `201`, заметка появляется вверху списка карточки | Заметка сохранена в таблице `notes` с текущим timestamp |
| 7 | Редактирование заметки | Клик на кнопку «Редактировать» у заметки, ввод нового текста в диалоге | Запрос `PATCH /notes/:id` с новым текстом, статус `200` | Текст заметки обновлён в БД и на экране без перезагрузки всей страницы |
| 8 | Отмена редактирования заметки | Клик «Отмена» или отправка того же самого текста | Запрос на сервер не отправляется | Никаких лишних сетевых вызовов, текст прежний |
| 9 | Удаление отдельной заметки | Клик по кнопке «Удалить» у заметки и подтверждение в `confirm` | Запрос `DELETE /notes/:id`, статус `200` | Заметка удалена из БД и исчезает из DOM |
| 10 | Каскадное удаление книги | Удаление книги, у которой есть несколько заметок | Запрос `DELETE /books/:id`. Срабатывает правило `ON DELETE CASCADE` | Книга удалена, все связанные заметки автоматически удалены из БД |
| 11 | Персистентность данных (PostgreSQL) | Добавление книги и заметок, остановка сервера (`Ctrl+C`), повторный `npm start` и F5 | Все созданные данные сохраняются в PostgreSQL и не теряются | Полная сохранность данных после перезапуска |
| 12 | Сетевой сбой / Падение сервера | Остановка сервера и попытка добавить/изменить заметку | Перехват ошибки в `catch`, всплывающее уведомление об ошибке (Toast) | Интерфейс остаётся стабильным (Pessimistic UI) |
